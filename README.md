# SecureFile
### Құпиясөз арқылы файлдарды қауіпсіз шифрлау және жеке деректерді анықтау жүйесі

## 1. Жобаның мақсаты

SecureFile — пайдаланушының жеке файлдарын құпиясөз арқылы қорғауға арналған Java Desktop GUI бағдарламасы.

Жобаның негізгі мақсаты — файлдарды рұқсатсыз оқудан қорғау, олардың тұтастығын сақтау және ішіндегі жеке деректер белгілерін анықтау.

## 2. Жобаның негізгі мүмкіндіктері

- AES-256-GCM алгоритмі арқылы файлдарды шифрлау.
- Құпиясөз арқылы шифрланған файлдарды қалпына келтіру.
- PBKDF2WithHmacSHA256 арқылы криптографиялық кілт генерациялау.
- SecureRandom арқылы кездейсоқ Salt және IV жасау.
- Privacy Radar арқылы ЖСН форматына ұқсас сандарды, телефон нөмірлерін және email мекенжайларын анықтау.
- Үлкен файлдарды бөліктермен өңдеу.

## 3. Қолданылған технологиялар

- Java 17

- AES-256-GCM

- SecureRandom

## 4. Орнату нұсқаулығы

Жұмысты бастау үшін компьютерде Java 17 және Apache Maven орнатылған болуы қажет.

1. GitHub репозиторийін жүктеп алыңыз.
2. Жобаның негізгі бумасына өтіңіз.
3. Maven арқылы жобаны тексеріңіз:

```bash
mvn clean verify
```

4. JavaFX Maven Plugin конфигурациясы бар ортада бағдарламаны іске қосыңыз:

```bash
mvn javafx:run
```

## 5. Қолдану мысалы

1. SecureFile бағдарламасын іске қосыңыз.
2. «Файл таңдау» батырмасын басыңыз.
3. Қорғалатын файлды таңдаңыз.
4. Құпиясөз енгізіңіз.
5. «Privacy Radar» арқылы файлдағы жеке деректер белгілерін тексеріңіз.
6. «Шифрлау» батырмасын басып, шифрланған файлды сақтаңыз.
7. Файлды қайта ашу үшін шифрланған файлды таңдап, бастапқы құпиясөзді енгізіңіз.
8. «Дешифрлау» батырмасын басыңыз.

## 6. Қауіпсіздік ескертпесі

- Құпиясөзді басқа адамдарға бермеңіз.
- Құпиясөзді репозиторийде сақтамаңыз.
- Шифрлау кезінде кездейсоқ Salt және IV пайдаланылады.
- AES-GCM файлдың өзгертілгенін немесе қате құпиясөз енгізілгенін анықтайды.
- Құпиясөз жоғалған жағдайда файлды қалпына келтіру мүмкін болмауы мүмкін.
- Privacy Radar деректердің нақты дұрыстығын емес, көрсетілген үлгілерге сәйкестігін анықтайды.
